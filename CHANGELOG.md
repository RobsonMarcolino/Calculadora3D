# Changelog

Todas as mudanças notáveis neste projeto serão documentadas aqui.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/),
e este projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.2.0] - 2026-08-02

### Adicionado
- 🎉 Animação de confetti ao calcular preço (canvas-confetti)
- 🔄 Tela de loading animada com barra de progresso durante carregamento do modelo 3D
- 🏷️ Meta tags Open Graph e Twitter Card para preview rico ao compartilhar links
- 🤖 Configuração do Dependabot para atualizações automáticas de dependências
- 📋 CONTRIBUTING.md com guia de contribuição, estrutura do projeto e padrões de commit
- 📝 CHANGELOG.md para rastreamento de mudanças

### Melhorado
- 🌐 SEO: título em PT-BR, meta description aprimorada, canonical URL, theme-color
- 🏷️ `lang="pt-BR"` no HTML (era "en")

## [1.1.0] - 2026-07-xx

### Adicionado
- 📄 GitHub Pages deployment via Actions
- 🐳 Dockerfile + nginx.conf para deploy em container
- 📖 README em português com preview image

## [1.0.0] - 2026-07-xx

### Adicionado
- ✨ Dispositivo 3D fotorrealista com React Three Fiber
- 🎮 Interação: botões com press animation, knobs com rotação spring-based
- 🔊 Feedback tátil: sons sintetizados (Web Audio) + haptic feedback
- 📊 Motor de precificação calibrado ao mercado brasileiro (ID, LP, Pitch Deck)
- 🖥️ Fallback 2D automático quando WebGL não está disponível
- 📐 Editor de layout ao vivo (`?edit=1`) com Leva controls
- 🎨 Display dot-matrix com rolling number animation
- ℹ️ Modal de metodologia com tabela de preços e fontes
